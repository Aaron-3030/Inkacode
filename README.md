# InkaCode

**InkaCode** es una plataforma web de preguntas y respuestas orientada al aprendizaje y evaluación de conocimientos relacionados con **Ingeniería de Sistemas e Informática**.

El proyecto busca ofrecer una forma dinámica e interactiva de poner a prueba los conocimientos de los estudiantes mediante preguntas organizadas en diferentes áreas de la informática.

## Objetivo

Desarrollar un Quiz educativo que permita a los usuarios evaluar y reforzar sus conocimientos mediante preguntas de diferentes temas relacionados con el área de sistemas.

## Temáticas

El Quiz estará compuesto por diferentes categorías, entre ellas:

*  Programación
*  Sistemas Operativos
*  Redes
*  Bases de Datos
*  Seguridad Informática
*  Ingeniería de Software
*  Algoritmos y Estructuras de Datos
*  Tecnologías de la Información

Las categorías podrán ampliarse conforme avance el desarrollo del proyecto.

##  ¿Cómo funciona?

El usuario podrá:

1. Seleccionar una categoría.
2. Iniciar un Quiz.
3. Responder una serie de preguntas.
4. Recibir una puntuación según sus respuestas.
5. Conocer cuáles fueron sus respuestas correctas e incorrectas.
6. Consultar sus resultados.

La idea es que la plataforma sea sencilla de utilizar y, al mismo tiempo, permita convertir el aprendizaje en una experiencia más dinámica.

##  Características principales

* Sistema de preguntas y respuestas.
* Preguntas organizadas por categorías.
* Sistema de puntuación.
* Resultados al finalizar el Quiz.
* Interfaz web interactiva.
* Diseño adaptable a diferentes dispositivos.
* Posibilidad de ampliar las categorías y preguntas.
* Registro de progreso del usuario *(funcionalidad prevista)*.
* Ranking de usuarios *(funcionalidad prevista)*.

## Instalación y ejecución

Para ejecutar InkaCode de manera local, sigue los siguientes pasos.

### 1. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/Aaron-3030/Inkacode.git
```

### 2. Entrar al proyecto

```bash
cd Inkacode
```

### 3. Abrir el proyecto

Puedes abrir el archivo `index.html` directamente en tu navegador.

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto durante el desarrollo.

### Requisitos

Actualmente, InkaCode no requiere instalaciones adicionales ni dependencias externas.

Solo necesitas:

* Git
* Un navegador web moderno
* Visual Studio Code (recomendado)

Si ya tienes una copia del proyecto y quieres obtener los últimos cambios:
